# 什麼是過程導向\(待補\)

## 什麼是過程導向\(待補\)

將每個程式看成是一個一個步驟。

假如你想去電影院看美國隊長，就要買一張電影票，有電影票以後，還要到電影院去，到了電影院後，還要等待你的場次，時間到了以後，工作人員會幫你驗票，驗票完後才可以進入到影廳裡找你的位子。

這整個過程當中，是由許多步驟組合起來的，過程導向就是這樣。一個步驟一個步驟地完成整個程式碼。

## 排列問題

### 主要學習

for 循環的寫法，閉區間操作符，字符串插值，類型標註，類型推斷，swap 函數，數組初始化，輸入輸出參數，泛型，元組。

### 問題

有 1、2、3、4 個數字，能組成多少個互不相同且無重複數字的三位數？這些組合，都是多少？

### 使用for循環

可填在百位、十位、個位的數字都是 1、2、3、4 組成所有的排列後再去掉不滿足條件的排列。最土的方法，直接使用三個 for 循環實現。

```swift
var i:Int = 1
var j:Int = 1
var k:Int = 1
var s = ""
var n = 0

for _i in 0..<5 {
   i = i + 1
    for _j in 0..<5 {
     j = j + 1
      for _k in 0..<5 {
         k = k + 1
         if i != j && j != k && k != i {
          s += "\(i) \(j) \(k), "
           n = n + 1
         }
      }
   }
}

print("n \(n)")
print("s \(s)")
```

對於 i ，表示將變量 i 插入到字符串，是 swift 字符串插值的一個用法。其中 j 便表示將變量 j 插入到字符串中等。

var 關鍵字用於聲明一個變量。 swift 是一個強類型安全語言，在聲明變量時，如果指定了初始值，即使沒有進行類型標註，swift 仍然可以進行正確的類型推斷。例如，對於聲明var s = " " , swift 將推斷出s的類型是 String 。同理，對於代碼 var n = 0，n的類型為 Int。

對於變量聲明 var n = 0，與 var n:String = 0 是一樣的。在這裡， String 緊隨變量名之後，便是類型標註。

當你在聲明常量或者變量的時候賦給它們一個字面量（literal value）即可觸發類型推斷。什麼叫字面值，上文代碼中的" "與0便是。關於類型推斷的一般性規則：

對於字面量為整型數字時，swift 總是推斷為 Int。 而對於小數，總是推斷為 Double，而不是 Float。例如 var sban = 3.15，變量類型便被推斷為 Double。 當字面量是一個表達式，而表達式同時含有小數與整數時，推斷為 Double。例如 var sban = 3.15 + 10，變量sban的類型便為 Double。
