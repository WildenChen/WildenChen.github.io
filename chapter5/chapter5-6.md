# 實體屬性和實體方法

在 5.2 曾講過，一個實體\(或者説物件\)具有3個要素，即識别字，狀態，行為。狀態是由實體屬性來描述的，行為是透過實體方法來表現的。

實體屬性\( instanceproperties \)儲存值，而這些值正是用來描述每個物件的狀態的。實體屬性以變數的形式表現的，定義在類別中，例如，一個長方形的寬與高是實體屬性，不同的長方形寬度和高度都不相同。一個長方形的寬度和高度的值，正是這個長方形的狀態。

實體方法\( instancemethods \)描述了這個實體可以有哪些行為，以函數的形式定義在類別中。方法又分為外部可存取的和外部不可存取的。外部不可存取的實體方法是描述類別中各個成員互相協作的內部邏輯，外部可存取的實體方法是這個物件對外界提供的服務，即這個物件可以幹啥事情。

必須先建立實體，再存取實體屬性和實體方法。如果只是建立了一個自定義類別，卻沒有建立該類別的實體，那還是無法在程式碼中存取該類別的實體屬性。

接著，我們來看如何宣吿實體屬性和實體方法，以及如何存取它們。

## 如何宣告實體屬性

在類別體中，即 “class 類別名稱{}”的括弧中，按如下格式寫入屬性的宣告。

```swift
var 屬性名稱:屬性類型 = 值
```

在宣吿時，能直接給屬性值就給屬性預設值，而不要給予可選值，除非有使用可選值的必須性，或是懂得完全應用建構式時，才能考慮其他的應用方式。

在 var 關鍵字前，可以加上存取控制 internal、public、private、open、fileprivate 標識。如果不加存取控制，則預設為 internal。

## 如何宣告實體方法

在 swift 中有兩種宣吿實體的方法，但存取方式是一樣的。第一種是其他 OOP 語言相同的標準宣吿方法。另一種是 類似 Python 特殊的宣吿方式，無論標準的還是特殊的實體方法宣吿，都是定義在類別體中的。

我們先講一下標準的宣吿方法。標準的宣吿方法格式如下：

```swift
func 方法名稱(參數...) -> 回傳值類型{
    // 方法內容
}
```

如果要加上存取控制\(open、public、fileprivate、private \)，要寫在 func 關鍵字前面。預設的存取控制和實例屬性一致，都是 internal。

而參數可分為內部參數與外部參數，外部參數雖然可以省略，但是對於公開或是可外部存取的方法，建議還是取有意義的相關名稱，才易於閱讀與使用。

另一種特殊的宣吿方法，是將方法宣吿為 func 類型的實體屬性。在執行時，使用這種方法有其靈活的地方。

這種方法一般在進階應用中才會用到。該方法學起來不難，難點是掌握好何時運用它。如果錯用濫用，發生錯誤將是難以偵錯和維護的。

以下內容建議程式設計新手暫時略過，只建議 OOP 經驗較豐富的用戶瞭解。

```swift
var 方法名稱:(參數...) -> 回傳值類型{
    // 方法內容
}
var doSomething:() -> Void = { println("doSomething!") }
```

常用的應用是把方法當成一個變數，不給予任何內容與預設值，在其他地方再給予相對應的函數，可以在執行時隨時替換相對應的方法，甚至相該類似的方法給予存取甚至控制事件流程。

詳見雄獅企業入口的 DisplayObject.swift

```swift
var mEventHandlers:[ (String,(target:DisplayObject) -> Void )] = []
func addEventListener(aEventName:String,aHandler:(target:DisplayObject) -> Void){
        mEventHandlers.append((aEventName,aHandler))
        NSNotificationCenter.defaultCenter().addObserver(self, selector: "onEventHandler:", name: aEventName, object: self)
    }
```

## 如何存取實體屬性和實體方法

必須先建立實體，才能存取實體屬性和實體方法，一個實際的已建立出來物件才會有實體屬性的值。實體方法指和這個實際物件綁定的方法。

建立之後，就可以使用「.」 運算子來存取實體屬性和實體方法。
