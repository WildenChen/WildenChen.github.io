# Class 的成員

Swift 中 Class \(類別\)的構成，和其他 OOP 語言並沒有什麼大的不同，主要有以下幾個部分。

* Class 的名稱和套件路徑\(namespace\)
* 構造函數
* 屬性：包括實例屬性\(Instance properties\)
* 方法：包括實例方法\(Instance method\)和類型方法\(type method\)/靜態方法\(static method\)

Swift 中 class 有一些特殊的地方，例如存取控制、類別體\(Class Body\)中可以插入可執行語句。

Swift 中對類別成員和類別的存取控制有重要改變，不僅與其他語言有所不同，與 Objective-C 相比也有相當大的改變。本章只講述類別的構成部分，將關於存取控制\(Access Control\)部分與結構\(struct\)只先簡單帶過。

所謂對成員的存取控制，即外部的程式碼能不能調用物件的某個成員。

套件名稱，即命名空間\(namespace\)與其他語言有極大的差異，在其他語言中，命名空間通常是類別的目錄與分類，在 Swift 中，一個套件為一個專案，專案名稱為套件名稱，即命名空間。

在學習本章節時，只需要知道存取控制有以下幾點變化：

* 所有成員的預設存取控制是 internal\(套件內可見\)，而不是 public\(公開\)。
* 不僅類別的成員有存取控制，類別本身也有存取控制。預設的類別存取控制也是 internal。
* 所謂 internal，指同一個套件裡的其他類別可存取，對其它套件不可見。
