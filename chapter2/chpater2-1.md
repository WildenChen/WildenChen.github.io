# 資料的本質與重要性質

資料是一切程式設計語言的基石。

在 Swift 中，我們非常熟悉的所有數值，比如畫面的大小、使用的圖片名稱、 App 的版本及支援的裝置等等，都是透過資料來描述的。我們給資料起了各種各樣的名字，這些名字就是通常所説的變數\(variable\)，透過變數\(variable\)來調用資料。

資料到底是什麼？有哪些型別？變數又是怎樣與資料發生聯繫呢？

## 一切都是物件\(Object\)

Swift 中所有的資料都是物件。

「一切皆物件。」

這句話很耳熟，英文原文是「Everything is an Object」出自於「Thinking in Java」。 Swift 和 Java 、 C\# 一樣，是純粹的物件導向語言。

### Swift 中資料型別概述

和其他物件導向語言\(Object-oriented Language\)一樣，Swift 的資料型別也分為基本資料型別和複雜資料型别，這兩種資料型別不僅僅是概念上的區分，在使用方式上也很不一樣。

基本資料型別\(primitive data type\)是我們在程式設計時要頻繁使用到的資料型別，比如説 數字、文字、條件真假，有些程式設計經驗的人都知道，這是語言的基本構成單元。

Swift 中預定義的基本資料型別一共有：Int、Float、Bool、String、UInt等。

其中，Int、Float、UInt是處理數字的。

* Int 用來處理整數。
* Float 用來處理有小數點的數字。
* UInt處理很大的正整數。
* String是處理文字的，稱為字串。
* Bool，又稱布林值，用來標識真假。這種型別的資料只有兩個，一個是真\(true\)，一個是假\(false\)。

複雜資料型別\(complex data type\)是相對於基本資料型別而言的。 簡單的複雜資料型別，往往是由一些基本資料型別構成的。 如 陣列 \(Array\) ，可以直接由一些數字\(或者字串\)作為元素組成。 更高級一點的複雜資料型別，其組成元素也是複雜資料型別。比如説一個類別物件，它含有 3 個 Array 。可以這樣一直嵌套下去，組成很複雜的資料型別。

經常用到的 Swift 複雜資料型別有： Array 、 UIView 、 Dictionary 、Optional \(可選值\)。 我們自己定義的類別也全部屬於複雜資料型別。

> 在 Swift 中，Option 值，是把型別的變數在往外面多包裝了一個類似Bool的空值\(nil\)，所以 Option 值不能當成是簡單資料型別，雖然某些用法雖然和簡單型別類似，但那只是 Swift 包裝過而已。
