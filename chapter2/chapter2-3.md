# 常數與變數

## 常數的宣告

被宣告為常數的物件

```swift
  let _myName:String = "Sheila"
```

## 變數的宣告

```swift
  var _myName:String = "Sheila"
```

## 常數:代表不能被修改的

```swift
let _name:String = ""
_name = "123"
//error，can't change value
```

## 變數:代表可以被修改

```swift
  var _myAge:Int = 23
  _myAge = 24
  print("myAge is \(_myAge)")
  //myAge is 24
```
