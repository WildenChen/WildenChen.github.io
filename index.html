Restructure strategy

先分層，再逐步現代化

目前 repository 已有早期 GitBook 章節、首頁、portal 子頁、服務資料與文件。這次先保留既有章節路徑，讓舊文章透過 Legacy Articles 查閱；新的 AI Portal 則放在根目錄首頁與五個清楚的靜態子入口。

Guiding rules

重構守則

  • 保留歷史：不刪除、不覆蓋舊 Swift / iOS Markdown。
  • 入口分離：新首頁與 Legacy Articles 分開，避免新舊內容混雜。
  • 簡單穩定：暫不導入大型 framework，維持 GitHub Pages 可直接部署。
  • 低調公開：所有 HTML 保留 robots meta，並用 robots.txt 阻擋索引。
