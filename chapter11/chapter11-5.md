# Swift CocoaPods

推薦的第三方：

1. LionEvents：事件監聽框架
2. Alamofire：網路下載工具
3. SwiftyJSON：JSON 字串解析
4. ReachabilitySwift：判斷網路連線
5. pop：Facebook出品的補間動畫工具
6. MBProgressHUD：簡單風格的載入與提醒的 UI 集合
7. Flurry-iOS-SDK/FlurrySDK：Yahoo 的使用者行為記錄套件
8. GoogleAnalytics：Google 的使用者行為記錄工具
9. RMUniversalAlert：自動處理掉 iOS7 與 iOS8 的 Alert UI
10. Charts：圖表繪製套件
11. TPKeyboardAvoiding：簡易避免鍵盤蓋住輸入框
12. SDWebImage：簡易非同步載入圖片，有記憶體與硬碟快取管理功能
13. Material：仿 Android UI 的 UIKit。
