Agent research

OpenClaw

OpenClaw 是個人 AI Agent 的公開研究入口。這裡只整理能公開分享的架構：記憶、工具呼叫、主動巡檢、風險判斷與回報格式。

00 / Matrix

公開能力矩陣

Capability Public Description Private Boundary
Memory 保存專案脈絡、決策理由、偏好與巡檢摘要，讓 Agent 不必每次重頭理解。 不公開個人記憶原文、憑證、私密人格設定或未整理的原始資料。
Tool Use 把本機檔案、瀏覽器、GitHub、知識庫與服務狀態檢查變成可控行動。 公開站只放架構與入口，不提供執行工具或控制內網服務的能力。
Decision Gates 在推送、公開、刪除、暴露設定前做風險檢查，降低誤操作機率。 實際規則與敏感清單留在私有工作區，不放到 GitHub Pages。
Reports 把執行結果寫成短、清楚、可接續的技術回報。 只公開可分享版本，內部錯誤、帳號、URL 與 token 一律遮蔽。
01

Memory

把專案、決策、偏好與巡檢結果整理成可追溯的長期記憶。

02

Tool Use

把檔案、瀏覽器、GitHub、行事曆與本機工具變成可控的行動能力。

03

Inspection

主動檢查網站、服務狀態、連結品質與公開風險。

04

Decision Gates

在推送、公開、刪除、暴露私密資訊前先做風險判斷。

05

Reports

把技術結果寫成短、清楚、可接續的回報，而不是留下零散紀錄。

06

Public Boundary

公開頁只描述能力與方法，不放私密人格設定、憑證或內部記憶內容。
