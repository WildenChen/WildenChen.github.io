資料型別、變數與常數宣告、可選值（Optional）、運算子與保留字。

if-else 條件判斷、陣列與 for 迴圈、過程導向程式設計思維。

函數的四種定義方式、參數傳遞、函數本質與 closure 進階應用。

類別與物件

Class 定義、成員屬性與方法、構造函數（init）、self 關鍵字與方法重載。

封裝的概念與原則、存取控制（public / private）、get / set、套件命名空間。

 07
複合與繼承

物件複合（has-a）、繼承（is-a）的區別與實現方式，多層繼承關係設計。

 08
多型與轉型

類型檢查（is / as）、上轉型（Upcasting）與下轉型（Downcasting）實戰。

 09
協定與委派

Protocol 定義與遵從、Delegate 模式原理，iOS SDK 中最核心的設計思維。
