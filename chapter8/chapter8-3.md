# 本章小結

我們已經學到了多型的原理和實際的實例。多型就是多種型態。型態運用的微妙之處就在於各種形態之間的轉換。

在這一章，我們才真正看到了 OOP 的威力。

沒有對資料的 OOP ，就不可能有類型與物件的存在。

沒有類型，就不可能有繼承的關係存在。

沒有繼承，則不可能實現多型。

在這些範例中，大家應該體會到了多型的強大靈活性。在實際應用中，多型是 OOP 程式設計日常工作的基石。我們同時也學習了重要的里氏代換原則\(LSP原則\)。里氏代換原則，要時刻記在心上，這將是我們日後進階學習進階 OOP 程式設計設計模式的基礎。

然而，多型不僅僅體現繼承的關係上，也不僅僅是在父類別和子類別的相互轉換上，在下一章，我們將接觸到更加強大的資料類型：協定與委派。 協定與委派也是描述資料類型的，所不同的是它們更加抽象。
